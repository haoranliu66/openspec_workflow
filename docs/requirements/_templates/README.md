# 共享需求包

一个共享需求包承载一个长期产品主题，可由多个 OpenSpec changes 分批交付。

复制本模板创建 `docs/requirements/REQ-<id>-<slug>/`。目标项目是否把需求包和详细 change/archive 一并提交 Git，由目标团队的审计与保密策略决定；工作流安装器不设置该策略。

## 基本信息

- **需求 ID**：REQ-000
- **标题**：
- **负责人**：
- **状态**：调研中 / 已批准 / 交付中 / 已完成 / 已停用

## 文档

- `BR-000.md`（由模板 `BR.md` 复制并按真实 ID 改名）：为什么做、业务结果与约束
- `PRD-000.md`（由模板 `PRD.md` 复制并按真实 ID 改名）：为谁做、做什么及结果级验收
- `FEATURE.md`：已经交付并可使用的能力
