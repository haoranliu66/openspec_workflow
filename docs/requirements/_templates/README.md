# 共享需求包

一个共享需求包承载一个长期产品主题，可由多个 OpenSpec changes 分批交付。

## 基本信息

- **需求 ID**：REQ-000
- **标题**：
- **负责人**：
- **状态**：调研中 / 已批准 / 交付中 / 已完成 / 已停用

## 文档

- [BR](BR-000.md)：为什么做、业务结果与约束
- [PRD](PRD-000.md)：为谁做、做什么及结果级验收
- [FEATURE](FEATURE.md)：已经交付并可使用的能力
